# **App Name**: Diabetic Delights

## Core Features:

- Multi-Language Support: Offer content in Arabic, English, and Russian to cater to a diverse user base.
- Categorized Meal Listings: Organize meals into categories such as breakfast, lunch, dinner, snacks, and desserts for easy browsing.
- Product Pages with Detailed Information: Provide a dedicated page for each dish with an image, multilingual name and description, calorie count, and price.
- Shopping Cart: Enable users to add desired items to a shopping cart for easy checkout.
- Favorites List: Allow users to save their favorite dishes for quick access.
- User Account Management: Allow users to manage the languages displayed on the interface
- Image generation for dish previews: When dishes are added by the administrator without providing an image, generate one automatically using an AI image generation tool.

## Style Guidelines:

- Primary color: Soft green (#A7D1AB), symbolizing health and natural ingredients.
- Background color: Light beige (#F5F5DC), providing a neutral and comforting backdrop.
- Accent color: Muted orange (#E59554), used for interactive elements and call-to-actions.
- Body and headline font: 'Alegreya', a serif font with an elegant, intellectual feel suitable for headlines and body text.
- Use simple, line-based icons for navigation and categories to maintain a clean and modern look.
- Implement a clean, grid-based layout with clear separation between sections and elements.
- Use subtle transitions and animations to enhance user experience without being distracting.
